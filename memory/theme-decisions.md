Ответы пользователя 15.11.2026 перед стартом светлой темы (тёмная — потом, отдельным шагом):

- **Клапаны** GPV/VPV — «как сейчас»: красный закрыт, зелёный открыт, те же картинки `Valve_red.png`/`Valve_green.png`. Я предлагал серые по ISA — отказ.
- **Насосы PUMP ON/OFF, PREHEAT, MICROWAVE, пауза рецепта** — «как сейчас»: лососевый/зелёный (`Res.OnGreen`), `IndianRed` у паузы. Тема эти цвета состояний не трогает.
- **Кнопки газов H2/CH4/N2/O2/Ar/H2_2** — оставить цвета баллонов (стандарт маркировки).
- **Поля показаний** (расходы, давления, температуры, мощность; были синие с белым) — белое поле, тёмные цифры.

**How to apply:** тема меняет фон, секции, рамки, кнопки, поля значений, графики и панель; цвета, несущие смысл состояния (клапаны, насосы, вкл/выкл, светофорные статусы, баллоны), остаются прежними, пока пользователь не скажет иначе. Связано с [[ui-layout]].

## Как устроено (Theme.cs)

`Palette` (роли цветов + флаги `Classic`, `Dark`), три экземпляра `Theme.Old/Isa/Dark`, `Theme.All`, `Theme.Current`, `Theme.Select(p)` — перекраска на ходу всех `Application.OpenForms` + событие `Theme.Changed`.
- При первом `Theme.Apply(control)` снимается `Snapshot`: собственные (не унаследованные) Back/ForeColor через внутренние `ShouldSerializeBackColor/ForeColor` (рефлексия), FlatStyle, UseVisualStyleBackColor, BorderStyle, роль. Роль — по собственному цвету из Designer (не по унаследованному, иначе при старте в Old всё путается). `ControlAdded` красит позже добавленные контролы.
- **Old = Classic**: всё возвращается к снимку, т.е. ровно как до редизайна темы (системные цвета, 3D-рамки, стандартные кнопки, синие поля, чёрные трубы, стандартный рендер меню).
- Роли: Form, Section, Inset, Plain, ButtonNeutral, ButtonColored (цвет не трогается — насосы, баллоны), Measured, Setpoint, Combo, Pipe, Track (полосы Preheat/Turbo), Logo (в Dark — логотип перекрашен в серебро), List, Chart.
- Нейтральная кнопка меняет фон только если сейчас нейтральная/цвета прежней темы — зелёный «включено» при переключении не теряется.
- Текст: явный чёрный/ControlText на прозрачном фоне → `Text`; в Dark ещё и любой тёмный (L<0.12). Метки на собственном цветном фоне (камера, табличка статуса) не трогаются.
- Dark: тёмная рамка окна (DWM attr 20), тёмные скроллбары (`SetWindowTheme DarkMode_Explorer`) у списков, многострочных TextBox, ScrollBar; стрелки NumericUpDown рисуются поверх (`PaintSpinner`); заголовки ListView — owner-draw (кроме Old); линии графиков с яркостью < 0.18 осветляются к белому (чёрный N2, синий Incident/Ch1), остальные как есть.
- Меню/панель: `Theme.Renderer` (глобально `ToolStripManager.Renderer` + база `ToolbarRenderer`), цвета из `ToolColors`, в Old — базовые. Иконки меню через `Theme.Glyph(item, glyph, size)` — реестр, перерисовываются при смене темы (кроме красной Start Logging и белого крестика при наведении).
- Созданное кодом с цветами темы (полосы, заголовки графиков, главная полоса, подсветка открытого графика) перекрашивается в обработчиках `Theme.Changed` (TrendDock.RepaintTheme, MainForm).
- `Theme.Apply(this)` — в конце конструктора каждой формы, у MainForm после `new SchemeScaler` (скейлер ищет трубы по чёрному), у отдельного окна графика — в TrendDock.

## 15.11.2026, третья итерация (после просмотра сборки)

- Названия в окне: **Default** (бывш. Old, ключ в ini по-прежнему `Old`), **Light Mode** (бывш. ISA-101, ключ `ISA101`), **Dark Mode** (`Dark`). Без настройки в ini открывается Light Mode.
- Light Mode: пользователь попросил убрать синие акценты — «в том же стиле, как сама тема, просто чуть потемнее». Уставки теперь серое поле (204,208,214) с тёмным текстом (28,30,33) против белого поля измеренного; подсветка открытого графика (210,213,218); Accent (выбор, поднятый заголовок графика, рамка выбранной карточки) тёмно-серый (88,94,104). В Dark синие акценты остаются (фирменные).
- Dark: системные линии сетки ListView (`GridLines`) были «вырвиглазные» в Fault Status. Только в Dark `GridLines` выключается, строки рисуются сами (`DrawListCell`), сетка — Border, смешанный с фоном списка на 35 %; выделение — Accent. В Light сетка и строки родные (пользователь: «в light не надо было выключать»), свои только заголовки столбцов; в Default всё родное.

## 15.11.2026, камера в Dark (не собрано)

Пользователь: камера на мнемосхеме «выбивается» в тёмной теме — **менять только Dark** («я только про тёмную тему говорю»). Камера нарисована RichTextBox'ами (ChamberHead, ChamberDown — ControlDark; ChamberBottom — ControlDarkDark; richTextBox2/3 столик — ControlLight; richTextBox1 волновод — ControlDark; richTextBox5 оранжевая молния — не трогается) и метками Ch1/Ch2/1/2 на ControlDark. Раньше RichTextBox имел Role.None. Теперь роль `Hardware` (по собственному цвету фона), цвета в палитре `Body/BodyShade/BodyLight/BodyText` заданы только у Dark: сначала корпус (44,60,112), низ (30,42,84) — «сливается», осветлено: корпус (82,100,156), низ (58,74,126), столик (196,202,220), подписи (230,233,244), у RichTextBox рамка None. У палитр без Body — восстановление снимка.
